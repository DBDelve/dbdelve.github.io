Why −40 m

Stop paying for your DB Client, with cash or with memory.

I wanted something which is performant, modern and consumes little RAM. The existing DB clients are either filled with bloat (Electron and JVM) or paid. This is an alternative to them.

No feature is ever going behind a paywall.

Install −700 m

Get it running.

macOS, Linux and Windows builds come with every release.

macOS

# Homebrew is the recommended way. It installs and upgrades.
brew install --cask ShayanAbbas1/dbdelve/dbdelve
# It's signed ad-hoc, not notarized, so Gatekeeper refuses the first launch.
# Clear the quarantine flag once per install (an update is a new install):
xattr -dr com.apple.quarantine /Applications/DBDelve.app

Or take the .dmg and drag DBDelve to Applications. Apple Silicon, macOS 12 or later.

Linux

# From the AUR, packaged by @0PandaDEV. Thanks!
yay -S dbdelve-bin
# Or the tarball from the latest release. Installs under ~/.local, no root.
tar xzf dbdelve-*-linux-*.tar.gz && cd dbdelve-*-linux-*/ && ./install.sh
# Or the AppImage, one file that runs where it lands.
chmod +x dbdelve-*.AppImage && ./dbdelve-*.AppImage

x86_64 and aarch64, built on Ubuntu 22.04. Tarball · AppImage · full notes

Windows

  1. Download dbdelve-<version>-windows-x86_64.zip
  2. Unzip it wherever you like.
  3. Run dbdelve.exe. There's no installer.
